# Building a Router and Switch Network 🌐🛠️

## Welcome to My Networking Lab Adventure! 🚀

In this project, I rolled up my sleeves and built a fully functional network topology using **Cisco Packet Tracer**. From setting up routers and switches to configuring IP addresses and testing connectivity, this assignment gave me hands-on experience in creating and troubleshooting a small-scale network. If you’ve ever wondered how devices talk to each other across networks, this is the perfect place to start.

---

## What Was I Doing? 🤔

The goal of this lab was to design and configure a network consisting of:
- **Two PCs (PC-A and PC-B)** connected via a switch.
- **A router** to manage communication between subnets.
- **A switch** to connect devices within the same subnet.

I started by cabling the devices as per the topology diagram, then configured static IP information for the PCs. Afterward, I dove into the router and switch configurations to enable communication between the devices. Along the way, I encountered challenges like unresponsive pings and misconfigured settings—but hey, that’s where the real learning happens!

---

## Tools Used 🔧

1. **Cisco Packet Tracer**: The ultimate virtual lab for networking enthusiasts. It allowed me to simulate real-world network setups and test configurations.
2. **Router Commands**: Leveraged Cisco IOS commands to configure interfaces, set passwords, and enable IPv6 routing.
3. **Switch Configurations**: Set up VLANs, default gateways, and interface descriptions to ensure smooth communication.
4. **Ping and Connectivity Tests**: Used `ping` commands to verify end-to-end connectivity between devices.

---

## Skills Gained 💡

- **Network Topology Design**:
  - Learned how to cable devices and organize a logical network layout.
- **Router Configuration**:
  - Assigned IP addresses, enabled IPv6 routing, and configured security features like encrypted passwords and login banners.
- **Switch Management**:
  - Activated VLAN interfaces, set default gateways, and saved configurations to ensure persistence.
- **Troubleshooting**:
  - Diagnosed issues like failed pings due to firewall settings or missing router configurations.
- **IPv6 Implementation**:
  - Enabled IPv6 routing and verified its functionality using `show ipv6 route`.

---

## Fun Highlights 🎉

- **"Firewall Fiasco"**: Initially, my pings failed because both PC firewalls were active. Once disabled, I realized the router itself wasn’t configured yet—oops!
- **"Router Rescue"**: After configuring the router, I successfully established communication between PC-A and PC-B. Victory never felt so sweet.
- **"Lost Packet Mystery"**: Even after everything was set up, one packet got lost during testing. A reminder that no network is perfect!
- **"Command Console Wizardry"**: Typing commands like `enable`, `configure terminal`, and `ipv6 unicast-routing` made me feel like a true networking pro.
